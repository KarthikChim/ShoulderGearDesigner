# Archived Legacy Gear System

This directory contains the retired shoulder-gear GUI, tooth-generation,
optimization, simulation, and printable-prototype code.

The active application is the literature-only pitch-curve viewer launched by
`main.py`. Nothing in this archive is imported by the active application.

The archived tests are stored in `tests/` beside the code they exercised. They
are retained for reference and are not part of the active test suite.
